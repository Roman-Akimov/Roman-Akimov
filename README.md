## 🚀 Ключевые проекты (Избранное)

### 🐍 [MetETL](https://github.com/Roman-Akimov/MetETL) | *Профессиональный CLI-пакет для извлечения, обработки и BigData-анализа*
> **Суть:** CLI-инструмент на Python для автоматизации полного цикла ETL (Extract, Transform, Load) и статистического анализа открытой коллекции музея Метрополитен в Нью-Йорке (датасет > 470,000 объектов). Опубликован на **TestPyPI**.

<details>
<summary>⚙️ <b>Развернуть технические решения и архитектуру MetETL</b></summary>
<br>

* **Extract (pandas):** Быстрая фильтрация и потоковое чтение тяжелых CSV-файлов, генерация выборки случайных ID в JSON.
* **Transform & Асинхронность (aiohttp + asyncio):** Реализовал параллельный конвейер скачивания изображений, что **ускорило процесс в 6–7 раз** по сравнению с синхронными `requests`.
* **Image Processing (opencv-python + numpy):** Векторизованная обработка пикселей. Применение 4-х фильтров фильтрации (эффект Гаусса, оператор Собеля для детекции границ, гамма-коррекция $\gamma = 2.2$).
* **Analyze (matplotlib):** Расчет статистических метрик распределения по 16 отделам музея и генерация тепловых карт.
* **Архитектура и логирование:** Модульная структура пакета (`setuptools`, `build`, `twine`). Двухуровневое логирование (`logging`) с выводом в консоль (INFO) и ротацией в файл (DEBUG).

🔮 **Планы развития (Интеграция в Fullstack):**
Сейчас проектирую веб-интерфейс для пакета. Бэкенд: **Django REST Framework** + Django ORM для кэширования ответов API музея + **Celery** для выноса тяжелой пакетной обработки графики в фоновые воркеры. Фронтенд: Интерактивный дашборд-календарь и графики на **React**.
</details>
